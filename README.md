## 💻 How to Run using `.exe`

1. Double-click [`Launch_Court_Platform.exe`](Launch_Court_Platform.exe).
2. The terminal window will start the local server and show:
   `👉 http://localhost:5000/`
3. Copy and paste `http://localhost:5000/` into your browser.
4. The full Court Case Management & Judicial Analytics platform will open!
